# 📁 AFAR Ultimate v3.0 – ابزار معماری فایل و مهندسی معکوس

**AFAR (معماری فایل آماده برای هوش مصنوعی و مهندسی معکوس)** یک اپلیکیشن دسکتاپ قدرتمند و چند‌سکویی است که به شما امکان می‌دهد ساختارهای پیچیده از پوشه‌ها و فایل‌ها را از یک لیست متنی ساده بسازید، مهندسی معکوس هر پوشه‌ای را به یک خروجی آماده برای هوش مصنوعی تبدیل کنید، و مخازن گیت/گیت‌هاب خود را با یک رابط گرافیکی کامل مدیریت کنید.

## 🚀 نصب و پیش‌نیازها

### پیش‌نیازها
- **Python 3.8 یا بالاتر**
- **Git** نصب شده و از خط فرمان قابل دسترس باشد (برای قابلیت‌های گیت)
- کتابخانه **requests** (برای اتصال به API گیت‌هاب)

### نصب وابستگی‌ها
pip install requests
دریافت و اجرا
bash
git clone https://github.com/mahanneman/AFAR-Ultimate.git
cd AFAR-Ultimate
python afar_ultimate_v7.py
📖 نحوه استفاده
۱️⃣ ساخت ساختار
تب ساخت را باز کنید و پوشه مقصد را انتخاب کنید (روی مرور کلیک کنید).

لیست خود (درخت، گلوله، شماره، ایموجی) را در ناحیه ورودی خام جای‌گذاری کنید.

روی پردازش به ویرایشگر کلیک کنید تا لیست تمیز شود و پسوند فایل‌ها به‌طور خودکار تشخیص داده شوند.

در صورت نیاز نتیجه را در ویرایشگر زنده ویرایش کنید.

روی استقرار کلیک کنید – پوشه‌ها و فایل‌ها فوراً ساخته می‌شوند.

۲️⃣ مهندسی معکوس یک پوشه
تب معکوس را باز کنید و پوشه مبدأ را انتخاب کنید.

فرمت خروجی مورد نظر (درخت، JSON، XML، چک‌لیست مارک‌داون یا لیست تخت) را انتخاب کنید.

در صورت نیاز بر اساس گروه فایل یا پسوند خاص فیلتر کنید.

روی اجرای معکوس کلیک کنید – نتیجه در ناحیه خروجی ظاهر می‌شود.

از تب خروجی برای ذخیره نتیجه در فایل استفاده کنید.

۳️⃣ کار با گیت‌هاب
تب گیت‌هاب را باز کنید و توکن دسترسی شخصی خود (با دسترسی‌های repo و workflow) را وارد کنید.

روی ورود و ذخیره کلیک کنید – وضعیت توکن را مشاهده می‌کنید.

برای لیست مخازن روی به‌روزرسانی کلیک کنید.

برای ایجاد مخزن جدید، نام و توضیحات را وارد کرده و روی ایجاد کلیک کنید.

یک مسیر محلی برای مخزن تعیین کنید (جایی که می‌خواهید کلون یا کار کنید).

از کلون برای دریافت مخزن استفاده کنید، سپس از دکمه‌های کامیت، پوش و پول استفاده کنید.

درخت فایل را مرور کنید، روی هر فایل دوبار کلیک کنید تا در ویرایشگر باز شود، ویرایش کنید و روی ذخیره فایل کلیک کنید.

از بخش دستورات گیت برای اجرای دستورات دلخواه یا استفاده از ۵ اقدام سریع استفاده کنید.

همه عملیات‌های گیت در لاگ عملیات گیت ثبت می‌شوند.

🛠️ دستورات پیشرفته گیت
می‌توانید هر دستور گیت را با تایپ کردن در فیلد دستور دلخواه و کلیک روی اجرا اجرا کنید.
برای دسترسی سریع، پنج دستور رایج به‌صورت دکمه‌های یک‌کلیکی ارائه شده‌اند:

'''bash'''
git status

git log --oneline -10

git diff

git branch -a

git remote -v

## 📜 تاریخچه نسخه‌ها

### 🟢 V3 (نسخه‌ی فعلی)
نسخه‌ی کامل با قابلیت‌های اتصال به گیت‌هاب، ویرایشگر فایل، دستورات گیت و شخصی‌سازی پیشرفته.

### 🔵 V1 (نسخه‌ی پایه – قدیمی)
اولین نسخه‌ی AFAR فقط شامل موتورهای اصلی **ساخت** (ایجاد ساختار از لیست) و **معکوس** (خروجی گرفتن از ساختار پوشه) بود – بدون قابلیت‌های گیت‌هاب، دستورات گیت یا ویرایشگر فایل.  
اگر به ابزاری سبک و مینیمال فقط برای ساخت و مهندسی معکوس پوشه‌ها نیاز دارید، همچنان می‌توانید نسخه‌ی V1 را از [صفحه‌ی Releases](https://github.com/mahanneman/AFAR-Ultimate/releases) دانلود کنید یا با استفاده از تگ `v1.0` در مخزن به آن دسترسی پیدا کنید.

> **توجه:** نسخه‌ی V1 دیگر توسعه‌ی فعال ندارد، اما همچنان پایدار و کاملاً کاربردی برای موارد استفاده‌ی پایه است.
